# Contributing

See the repository-level [contribution guide](https://github.com/CheyLoveday/ExactCIs-public/blob/main/CONTRIBUTING.md)
for setup, required checks,
statistical change evidence, fixture policy, and the public package boundary.

The short rule is: declare the design and estimand, fail closed, keep the
method registry authoritative, and never alter an independent fixture until
its definition and oracle have been reconciled.

The [release roadmap](roadmap.md) keeps the Boschloo-only/T1-min 1.2.0 scope
separate from later proposals. The repository's manifest-bound checked reference
is a development tool; adding it does not register a new stable package method.
